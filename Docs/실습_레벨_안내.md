# GSD2 실습 레벨 안내

프로젝트는 `Study_Unreal_Shooter.uproject` 하나입니다. 시작 레벨은 `L_01_Shooter`입니다.
콘텐츠 브라우저에서 `Content/Course/Maps`를 열고 원하는 레벨을 더블클릭한 뒤 플레이합니다.

| 레벨 | 자료와 실습 | 조작 |
|---|---|---|
| `L_01_Shooter` | Blue 01~02의 함수·배럴·컨스트럭션 예제, Blue 04~06의 이동 표적·달리기·줌·2회 피격·HUD | WASD, 마우스, Space 점프, 좌클릭 발사, Shift 달리기, 우클릭 줌 |
| `L_02_Basics` | Blue 03의 조명 스위치·점수 아이템·플랫폼 이벤트 디스패처·스파크, C++ 01의 TestActor | WASD, 마우스, Space; 아이템과 플랫폼에 접근 |
| `L_03_ThirdPerson` | C++ 02~04의 마네킹 애니메이션과 C++ 캐릭터·Enhanced Input | WASD, 마우스, Space 점프, Shift 걷기 |
| `L_04_Dodgeball` | C++ 05~06의 탑다운 캐릭터·적 시야·자동 투척·충돌·일반 벽·투과 벽·승리 영역 | WASD; 금색 승리 발판에 진입하면 플레이 종료 |

서로 다른 Pawn/게임 모드가 필요한 중간 실습도 같은 프로젝트 안에 보조 레벨로 보관했습니다.

| 보조 레벨 | 내용 |
|---|---|
| `Content/Course/Basics/L_02_Framework` | BP_MyGameMode, BP_MyPawn, BP_MyPC의 BeginPlay 출력. 원문대로 Pawn에는 이동 기능이 없습니다. |
| `Content/Course/Basics/L_02_GanfaultAnimation` | Ganfault 캐릭터의 Idle/Run/Jump 애니메이션 |
| `Content/Course/ThirdPerson/L_03_MixamoAdam` | 마네킹으로 교체하기 전 Mixamo Adam 버전 |

## 레벨의 원본

- 삼인칭·닷지볼·Framework·Ganfault·Adam의 원본은 설치된 **UE 5.8 Third Person 기본 템플릿** `Content/ThirdPerson/Lvl_ThirdPerson.umap`입니다. 템플릿의 외부 액터 파일도 함께 복사했습니다.
- 각 복사본의 바닥, 경사로, 장애물, 조명, PlayerStart를 그대로 보존합니다. 임의로 생성했던 PracticeFloor와 JumpStep은 제거했습니다.
- 기초 실습은 자료 제공 `ThirdPersonBP/Maps/ThirdPersonExampleMap`을 통째로 복사하여 레벨 블루프린트의 참조를 유지합니다.
- 닷지볼에는 적 1개와 일반 벽·투과 벽·승리 영역만 추가합니다. 캐릭터 메시 회전은 Pitch 0 / Yaw -90 / Roll 0입니다.
- **버전 차이:** 강의의 UE 5.0 기본 맵과 설치된 UE 5.8 기본 맵의 지형은 다릅니다. 따라서 강의의 벽 좌표를 그대로 사용하지 않고, 기본 맵 북동쪽 장애물 옆에 일반 벽 `(1000,850,0)`, 투과 벽 `(800,1050,0)`, 적 `(1100,1070,100)`, 승리 영역 `(1550,650,0)`을 배치했습니다. 이 좌표는 현재 맵에 맞춘 배치이며 PDF 원문 좌표가 아닙니다.
- 변경 전 실습 레벨·스크립트는 `Saved/CourseBackup/before-template-fix-20261019-114934.zip`에 보관했습니다.

## 자료에 맞춘 값

- CalculatePower: `PlayerLevel * 7 + 25`; 레벨 3 → `POWER: 46`, 출력 10.9초.
- 컨스트럭션: 기본 테이블과 인스턴스별 소파. 배럴 충돌 시 연결된 불꽃 표시.
- 점수 아이템: 50점 추가 후 제거. 조명은 참조 유효성 검사 후 토글.
- TestActor: `VerticalSpeed=25`, Tick에서 `DeltaSeconds * VerticalSpeed`만큼 위로 이동.
- 슈터 표적: 속도 200, 5초마다 방향 반전. 첫 피격은 붉게 변경, 다음 피격은 폭발 후 제거하고 TargetsEliminated 증가.
- 슈터: 기본 속도 600, 달리기 2200. 줌 타임라인 0.3초, FOV 90↔45.
- HUD: PlayerHealth 1.0, PlayerStamina 1.0, PlayerCurrentAmmo 30, TargetsEliminated 0.
- 삼인칭: 캡슐 42/96, 카메라 붐 300, Shift 걷기 배율 0.4.
- 닷지볼: 카메라 붐 900, Pitch -70, 적 SightSource (10,0,80), 첫 투척 지연 0.5초·주기 2초.
- 닷지볼 구체: 반경 35, 물리 시뮬레이션, 수명 5초, 기본 InitialSpeed 1500. 최종 실습의 지연 생성은 InitialSpeed를 2200으로 지정한 뒤 FinishSpawning.
- PM_Dodgeball: 마찰 0.7, 반발 0.95. 일반 벽은 시야/공을 막고, 구리색 투과 벽은 시야/공을 통과시키며 캐릭터는 막습니다.
- 승리 영역은 원문대로 QuitGame을 호출합니다. 일반 벽과 투과 벽은 서로 붙는 L자 배치이며, 투과 벽의 회전은 Pitch 0 / Yaw 90 / Roll 0입니다.

Blue 06까지에는 체력·스태미나 소모, 재장전, 탄약 0 제한이 없습니다. 따라서 해당 기능을 추가하지 않았으며 발사를 계속하면 탄약이 음수가 될 수 있습니다. C++ 06까지의 공은 캐릭터에 닿으면 제거되며, 이후 장의 체력/피해 시스템은 포함하지 않았습니다.

## 구현 위치

- 슈터 그래프: `Content/FirstPersonBP/Blueprints`, HUD: `Content/FirstPersonBP/UI/HUD`.
- 기초 블루프린트: Content 루트의 FunctionExample, BP_Barrel, BPConstruction, BP_LightSwitch, BP_Collectable, BP_GameModeWithScore, BP_Platform, BP_Platform_Sparks, TestActor.
- C++: `Source/Study_Unreal_Shooter`의 MyThirdPersonChar, DodgeballCharacter, EnemyCharacter, DodgeballProjectile, Wall, VictoryBox.
- 실습용 게임 모드·캐릭터 파생 블루프린트: `Content/Course`.

원래 프로젝트의 `Variant_Shooter` 레벨과 `FirstPerson/Matarial` 작업물은 보존했습니다. 변경 전 설정과 기존 사용자 제작 표적은 `Saved/CourseBackup/before-course.zip`에도 보관했습니다.

## 버전 호환과 출처

강의와 일치하는 원본 노드·애니메이션·메시를 확보하기 위해 출판사의 공개 실습 저장소를 사용했고, 강의 PDF의 값과 최종 실습 범위를 우선 적용했습니다.

- [Blueprints Visual Scripting for Unreal Engine 5](https://github.com/PacktPublishing/-Blueprints-Visual-Scripting-for-Unreal-Engine-5)
- [Elevating Game Experiences with Unreal Engine 5, Second Edition](https://github.com/PacktPublishing/Elevating-Game-Experiences-with-Unreal-Engine-5-Second-Edition)
- 라이선스: `Docs/Licenses`.

UE 5.8에서는 구버전 VR 함수용 XRBase, 예제 설명 에셋용 GuidedTutorials를 활성화했습니다. 기존 Projectile 채널을 보존하기 위해 EnemySight와 Dodgeball은 각각 별도 채널 2·3을 사용합니다. C++ 클래스 경로는 CoreRedirect로 현재 프로젝트 모듈에 연결합니다.

## 검증 기록

- C++ 빌드: Unreal 5.8 Editor Development 성공.
- 관련 블루프린트 42개 컴파일 통과: `Saved/CourseVerification/asset-audit.json`.
- 기존 기능 검사 기록: `runtime-checks.json`, `extra-checks.json`. 이 기록은 템플릿 교체 전 결과입니다.
- 템플릿 교체 후 지형 보존 검사: `Saved/CourseVerification/template-layout.json`. 저장한 맵을 다시 열어 원본의 62개 액터를 비교합니다.
- 템플릿 교체 후 실제 PIE 검사 **38개 통과**: `Saved/CourseVerification/template-runtime.json`, 검사 스크립트 `Scripts/verify_template_stages.py`. 닷지볼은 적과 벽의 저장된 배치를 유지한 상태에서 검사합니다.
- 검증 코드는 `Scripts/course_runtime_verification.py`이며, 입력 주입은 개발용 `CourseVerificationLibrary`를 사용합니다. 저장된 레벨을 바꾸지 않고 PIE 복제 월드에서 검사합니다.

일반 사용 시에는 프로젝트를 열고 원하는 레벨을 플레이하면 됩니다. Scripts의 에셋 생성/다운로드 스크립트는 다시 실행할 필요가 없습니다.
